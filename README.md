# 📊 Desafio de Projeto — Power BI

Projeto desenvolvido como parte do **Bootcamp da DIO**, com o objetivo de praticar a criação e personalização de visualizações de dados utilizando o **Microsoft Power BI**.

## 🎯 Objetivo do Projeto

O desafio tem como objetivo desenvolver habilidades na criação de relatórios e visualizações no Power BI a partir do conjunto de dados disponibilizado durante o curso.

Neste projeto foi desenvolvida uma página de relatório para analisar **vendas, unidades vendidas e lucro por país e segmento**.

## 📈 Visualizações Criadas

O relatório contém os seguintes visuais:

* 🥧 **Lucro por Segmento** — gráfico de pizza apresentando a distribuição do lucro entre os diferentes segmentos.
* 🗺️ **Vendas e Unidades Vendidas por País** — mapa para análise geográfica das vendas e unidades comercializadas.
* 🗺️ **Lucro por País** — mapa apresentando a distribuição do lucro entre os países.

## 🛠️ Tecnologias Utilizadas

* Microsoft Power BI Desktop
* Power Query
* Visualização e análise de dados
* Git
* GitHub

## 📂 Arquivo do Projeto

O arquivo `projeto_powerBi_dio.pbix` contém o relatório desenvolvido no Power BI e está disponível neste repositório.

## 💡 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos como:

* Importação e utilização de dados no Power BI;
* Criação de gráficos e mapas;
* Configuração de campos e dicas de ferramentas (Tooltips);
* Personalização de títulos, cores e elementos visuais;
* Organização dos visuais em um relatório;
* Análise de dados por país e segmento;
* Versionamento e publicação de projetos utilizando GitHub.
